# Claude Code で導入する

ツピツピは、Claude Code などの AI に導入を任せることを前提にしています。
下の枠の中をそのまま Claude Code に貼り付けてください。わからないことは Claude Code が質問してくれます。

用意するもの:

- Claude Code や Codex などの AI ツールが使えるパソコン
- Cloudflare アカウント（無料プランで大丈夫です。画像保存用の R2 を使うため、カード登録が必要です）
- 使いたいドメイン（なくても `〇〇.workers.dev` で公開できます）

---

```text
EmDash 用ブログテーマ「ツピツピ」で、自分のブログを作って Cloudflare に公開したいです。
次の順で進めてください。各ステップの前に何をするか一言説明し、
私の操作が必要なとき（ログイン、カード登録、ドメイン設定など）は止まって手順を教えてください。

1. Node.js（22 以上）と pnpm が入っているか確かめ、なければ入れ方を案内する
2. https://github.com/hiroyukiw/tsupitsupi を新しいフォルダに取得し、
   テーマの更新を取り込めるように、取得元のリモート名を origin から theme に変える
3. CLAUDE.md と AGENTS.md を読んで、このテーマのルールを把握する
4. pnpm install を実行し、pnpm dev でローカル表示を確認する
5. 私にブログのテーマ（何について書くか）を質問し、seed/seed.json のメニューとカテゴリーを合わせる
6. wrangler で Cloudflare にログインし（ブラウザで私が承認します）、
   wrangler.jsonc のワーカー名・D1・R2 の名前を私のブログ用に変える
7. 公開の前に、Cloudflare の管理画面で R2 を有効にしてもらう（カード登録が必要。無料枠の範囲なら請求なし）。
   私が終えたら pnpm run deploy で公開する
8. 公開したアドレスの /_emdash/admin を開くと英語の初期設定画面が出るので、各項目を日本語で案内する
   （Site Title＝ブログ名、Tagline＝キャッチコピー、Sample content＝見本の記事とページを入れる、
   Your Email / Your Name＝管理者、Create passkey＝このブラウザにログイン用の鍵を保存）
9. 独自ドメインを使う場合は、Cloudflare でドメインをワーカーに割り当てる手順を案内する

守ってほしいこと:
- Cloudflare は無料プランのまま使う。有料プランが必要な設定（worker_loaders など）は有効にしない
- 秘密情報（API トークンなど）をファイルに書いたり、GitHub に上げたりしない
- わからない EmDash の仕様は、ドキュメント MCP（https://docs.emdashcms.com/mcp）で確認してから進める
```

## 公開したあと

- 見本の記事やページには「[キャッチコピー]」のような仮の文字が入っています。管理画面で自分の内容に書き換えてください
- トップページは、管理画面の 固定ページ ＞ ホーム のブロックで作ります
- 別の端末からもログインしたいときは、管理画面のセキュリティ設定でパスキーを追加します
- テーマを最新にするときは、Claude Code に「ツピツピを最新に更新して」と頼みます（手順は README の「バージョンと更新」）

## WordPress から引っ越す場合

（準備中）WordPress の記事を書き出して取り込むためのプロンプトを用意する予定です。
移行の代行も受け付けています。
