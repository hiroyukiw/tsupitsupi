# AI への指示例集

ツピツピで作ったブログを、Claude Code や Codex などの AI に手入れしてもらうときの指示の例です。
枠の中をコピーして、`[ ]` の部分を自分の内容に書き換えてから AI に貼ってください。

どの指示も、AI がブログのフォルダを開いた状態で使います。最初の1回だけ、次のように伝えておくと、テーマのルールに沿って作業してくれます。

```text
このフォルダは EmDash 用ブログテーマ「ツピツピ」で作ったブログです。
作業の前に CLAUDE.md と AGENTS.md を読んで、ルールに沿って進めてください。
Cloudflare は無料プランのまま使い、変更したら pnpm build が通ることを確かめてください。
```

公開中のサイトの記事や設定を AI に触ってもらうときは、AI が `emdash login` でサイトに接続します。ブラウザに出る画面で、あなたが「承認」を押してください。

## 見た目を変える

### 配色を変える

```text
サイトの配色を [落ち着いた紺とオレンジ] に変えてください。
src/styles/theme.css のトークン（--color-brand、--color-ink、--color-accent-soft など）だけを書き換え、
ライトとダークの両方で文字が読みやすいかも確かめてください。
```

AI は `theme.css` の色の値だけを変えます。部品のファイルには色を直接書かないのがテーマの決まりです。

### ロゴとファビコンを自分のものにする

```text
管理画面の「設定」→「一般」で、ロゴとファビコンを設定する手順を教えてください。
画像は [ロゴの画像ファイルの場所] にあります。
```

管理画面で設定すると、テーマの既定のロゴ（シジュウカラ）より優先されます。

## トップページ・メニュー・ウィジェット

### トップページの部品を並べ替える

```text
トップページ（固定ページ「ホーム」）の部品を、
[メインビジュアル → 記事一覧（新着6件）→ 強み → お問い合わせへの CTA] の順にしてください。
公開中のサイトの「ホーム」を emdash の CLI で書き換えてください。
```

### メニューに項目を足す

```text
グローバルナビ（primary）に「[プロフィール]」を足して、[/pages/about] へリンクしてください。
スマホの下部メニュー（mobile-bar）にも同じ項目を入れてください（4つまで）。
```

### サイドバーにプロフィールを置く

```text
サイドバーのウィジェットの一番上に、プロフィールを置いてください。
名前は [〇〇]、紹介文は [AI とブログで副業をしている会社員です] です。
```

## 記事を書く・整える

### 記事の下書きを作る

```text
「[ChatGPT と Claude の使い分け]」という記事の下書きを作って、公開中のサイトに下書きとして保存してください。
カテゴリーは [使い方]、見出しは h2 と h3 で、読者は [AI を使い始めたばかりの人] です。
公開はせず、私が管理画面で確認してから公開します。
```

### 記事にランキングを入れる

```text
記事「[おすすめのノートパソコン]」の「まとめ」の前に、ランキングを3位まで入れてください。
1位 [商品名A]（★4.5）、2位 [商品名B]（★4.0）、3位 [商品名C]（★3.5）、
ボタンは「公式サイトを見る」で、リンクはアフィリエイトリンクの [スラッグ] を使ってください。
```

### 比較表を入れる

```text
記事「[〇〇の選び方]」に、[商品A]・[商品B]・[商品C] の比較表を入れてください。
比べる項目は [価格、容量、保証期間、サポート]。おすすめは [商品B] の列にしてください。
良い・悪いは ◎ ○ △ × で書いてください。
```

### ボックスや吹き出しで読みやすくする

```text
記事「[〇〇]」を読んで、大事なところを「ポイント」のボックスに、
注意してほしいところを「注意」のボックスにまとめてください。文章の中身は変えないでください。
```

## 収益化

### アフィリエイトリンクを登録してボタンに使う

```text
管理画面の「アフィリエイトリンク」に、次のリンクを登録してください。
- スラッグ [amazon-book]、名前 [Amazon 本のおすすめ]、リンク先 [ASP で発行したリンク]
登録したら、記事「[〇〇]」の最後にアフィリエイトボタン「Amazon で見る」を置いてください。
```

### リンク先をまとめて変える

```text
アフィリエイトリンク [amazon-book] のリンク先を [新しいリンク] に変えてください。
このリンクを使っている記事がどれか、一覧で教えてください。
```

リンク先は一か所直すだけで、そのリンクを使っている全部のボタンが変わります。

### AdSense の広告を入れる

```text
記事「[〇〇]」の最初の h2 の前と、記事の最後に、広告枠を入れてください。
広告のコードは次のとおりです。
[AdSense で発行されたコード]
```

## 検索や SNS に向けて

### 説明文（description）を整える

```text
固定ページと記事のうち、SEO の説明文が入っていないものを一覧にして、
それぞれ 80〜120 文字くらいで説明文の案を出してください。私が確認してから反映してください。
```

### 記事の抜粋を書く

```text
抜粋（excerpt）が空の記事に、記事の内容を1〜2文でまとめた抜粋を入れてください。
```

## 公開と更新

### 変更を公開する

```text
いまの変更を pnpm build で確かめてから、pnpm run deploy で公開してください。
公開したら、トップページと [変更したページ] が正しく表示されるか確かめてください。
```

### ツピツピを最新版に更新する

```text
ツピツピを最新版に更新してください。
theme という名前のリモートから最新のタグを取り込み、CHANGELOG.md で今回の変更点と、
私がやる作業（管理画面の設定の追加など）があるかを教えてください。
ぶつかる部分があれば、私のブログの変更を残す形で直してください。
```

更新の手順は README の「バージョンと更新」にもまとめています。

### アクセス解析を入れる

```text
Cloudflare Web Analytics を使えるようにしてください。
Cloudflare の画面でサイトを追加する手順を教えてもらい、
表示されたトークンを wrangler.jsonc の vars に入れて公開してください。
```

### 独自ドメインを使う

```text
Cloudflare で買ったドメイン [example.com] を、このブログに割り当ててください。
wrangler.jsonc の routes に設定して公開し、表示されるか確かめてください。
```

## 困ったとき

### 表示がおかしい・エラーが出る

```text
[〇〇のページ] が [真っ白になる／エラーが出る] ようになりました。
原因を調べて直してください。直す前に、何が原因だったかを教えてください。
```

### 変更を元に戻す

```text
[昨日] からの変更を取り消して、元の状態に戻したいです。
git の履歴を見て、どの変更を取り消すか確認してから戻してください。
```

公開中のサイトの記事は、管理画面の各記事の「リビジョン」から前の版に戻せます。
