# ツピツピ（tsupitsupi）

EmDash 用のブログテーマです。AI ツールを使って発信する収益ブロガー向けに作っています。

- 公式サイト: https://tsupitsupi.com （準備中）
- ライセンス: MIT（無料コア）
- 動作環境: EmDash 1.x / Astro / Cloudflare Workers（無料プランで動作）

## かんたん導入（Claude Code におまかせ）

ツピツピは「Claude Code などの AI に導入を任せる」ことを前提にしています。
[docs/ai-setup.md](docs/ai-setup.md) のプロンプトを Claude Code に貼り付けるだけで、
インストールから Cloudflare への公開まで進められます。

## 手動で始める場合

```bash
pnpm install
pnpm dev         # http://localhost:4321
```

初回に管理画面を開くとセットアップ画面が出ます。そこで `seed/seed.json` のデモ記事・メニューを入れられます。

管理画面は `http://localhost:4321/_emdash/admin` です。

Cloudflare へ公開するときは `pnpm wrangler login` のあと `pnpm run deploy` を実行します。初回の公開で `wrangler.jsonc` に書かれた名前の D1（データベース）と R2（画像保存）が作られます。R2 の利用には Cloudflare にカード登録が必要です。

## 無料コアに入っているもの

- トップページをブロックで組み立て（メインビジュアル、強み・バナー・スライド、記事一覧、CTA、自由入力）
- 記事に入れるブロック: ボックス（ポイント・注意・警告・メモ・良い点・悪い点）、吹き出し
- 2カラム／1カラム／フルワイド（LP）のレイアウト切り替え
- ドロップダウン付きグローバルナビ、目立つ CTA ボタン、スマホ用サイドメニュー、スマホ下部メニュー
- ウィジェットエリア（サイドバー、メインの上下、記事の下、スマホメニュー内、フッター）
- 目次（本文中とサイドバー追従）、パンくず、シェアボタン、著者欄、前後の記事、関連記事、人気の投稿
- 記事一覧、カテゴリー・タグ一覧、検索、RSS、SEO メタ情報・構造化データ（JSON-LD）
- ダーク／ライトモード

## 管理画面での編集

- **トップページ**: 固定ページ「ホーム」のブロックを追加・並べ替えします
- **メニュー**: グローバルナビ、スマホ用メニュー、CTA ボタン、スマホ下部メニュー、フッターメニュー
- **ウィジェット**: サイドバーなど各エリアに追加します
- **人気の投稿**: 記事にタグ「人気」を付けると表示されます
- **ボックス・吹き出し**: 記事の本文で「/」を押して「ボックス」「吹き出し」を選びます。吹き出しのアイコンはメディアから選べます

## アクセス解析

Cloudflare Web Analytics（無料、Cookie なし）に対応しています。Cloudflare の管理画面の「Web Analytics」でサイトを追加し、表示されたコードの `token` の値を `wrangler.jsonc` の `vars` に入れてデプロイすると、全ページに計測タグが入ります。

```jsonc
"vars": { "CF_WEB_ANALYTICS_TOKEN": "表示されたトークン" },
```

ランキング・比較表・広告枠などの収益化ブロックも、今後このテーマに無料で追加していきます。

## フォルダ構成

```
src/
  components/
    core/     どの用途でも使う部品（ヘッダー、フッター、2カラム枠など）
    blog/     ブログ固有の部品（記事カード、目次、シェアボタンなど）
    blocks/   固定ページのブロック（メインビジュアル、CTA など）
    widgets/  ウィジェットエリアの表示
  layouts/    全ページ共通のレイアウト
  pages/      各ページ
  styles/     デザイントークン（tokens.css）、共通部品（site.css）、配色（theme.css）
seed/seed.json  コンテンツの型・メニュー・初期データ
docs/           導入手順・AI 向け資料
```

将来コーポレートなど別の用途を足すときは、`core` を共有し、用途ごとの部品とスタイルを追加する形で広げます。
